WEEKEND TRIP · MINAKAMI / TAKUMI NO SATO

水上・たくみの里
夏の週末旅

土合駅の山、川、夏の甘いもの、里山、温泉。
1泊2日、車でゆっくりまわる旅。

1泊2日友達と車移動夏旅

旅のルート

10:00 小山駅集合 → 車で水上へ。
山 → 川 → 夏スイーツ → 温泉 → 里山 → もう一度温泉。観光地を詰め込まず、旅の流れが気持ちよくつながる順番で。
小山駅 10:00→土合駅→谷川岳方面→大とろ牛乳→宿→たくみの里→鈴森の湯→小山駅

DAY 1｜山へ入る日

小山駅 10:00集合 → 土合駅 → 谷川岳方面 → 大とろ牛乳 → 温泉

10:00
小山駅 集合・出発

小山駅で集合して、友達の車で水上方面へ。荷物を積んで、ここから旅スタート。

集合車移動
12:00頃
土合駅

今回のHero Spot。モグラ駅の階段、地下ホーム、駅の外の山の空気まで楽しむ。

必須写真
12:45頃
谷川岳・一ノ倉沢方面

登山は無理せず、山・岩・緑・沢・木漏れ日を楽しむ。暑ければ短時間で切り上げる。

13:30頃
おすすめランチ

第一候補：そば処 角弥｜手打ちそば。
軽めなら：駅茶 mogura｜土合駅でカレーなど。
現地の混雑や営業時間を見て決定。

地元ごはん夏
15:00頃
菓子工房 大とろ牛乳

山と川を楽しんだ後の夏スイーツ。冷たい「大とろ牛乳」を旅の1日目のごほうびに。

必須夏スイーツ
16:00頃
大江戸温泉物語

チェックイン。ここからは観光を詰めず、温泉・部屋・夕食。

ほどける
EVENING
温泉 → 夕食 → もう一度温泉

夜はゆっくり。友達との時間を楽しむ。

DAY 2｜里山と余韻の日

朝風呂 → たくみの里 → 夏スイーツ → ランチ → 鈴森の湯 → 小山駅

MORNING
朝風呂・朝食

朝の温泉を楽しんで、ゆっくり出発。

10:00頃
たくみの里

古民家、田園、山道、小さな工房を散策。2日目は「山」ではなく「里」の空気へ。

必須里山
11:00頃
おすすめカフェ

第一候補：たくみカフェ｜かき氷・生乳ジェラート・自家製ドリンク。
候補：ファニーファーム｜週末ならブルーベリー系クレープ・アイス。
昼＋甘味なら Otowaya cafe｜地元食材の料理＋手作りケーキ。

夏スイーツ
12:00〜13:00頃
おすすめランチ

第一候補：たくみの里周辺でそば・郷土料理。
暑さが強ければ、カフェ＋軽めの昼食に切り替える。

13:30〜14:30頃
鈴森の湯

帰る前の最後の温泉。「まだ帰りたくない」をここでほどく。入浴後は水分補給して出発。

必須余韻
15:00頃〜
小山駅へ

帰り道も旅の一部。眠くなったら必ず休憩。小山駅で解散。
